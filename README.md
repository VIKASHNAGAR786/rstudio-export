# MCA Data Analysis Shiny App

This project is split into smaller files for readability:

- `app.R` - thin launcher that sources the app files
- `R/00_packages.R` - package imports
- `R/01_data.R` - Titanic preprocessing and mtcars model objects
- `R/02_ui.R` - dashboard layout
- `R/03_server.R` - server logic and outputs
- `www/style.css` - custom dashboard styling
- `www/logo.svg` - logo artwork
- `www/hero-illustration.svg` - hero banner illustration

## Run

Open `app.R` in RStudio and click **Run App**.

## Image options

If you want to replace the SVG artwork with Google images, good search terms are:

- Titanic ship illustration
- Blue dashboard hero background
- Ocean wave graphic
- Data analytics chart illustration

The included SVGs already work without downloading anything else.
